## §8 — build and hand-over

One Rust binary serves the English React app, worker, SQLite database and blob store. Server authorisation applies to search, downloads, exports and counts. Staff TOTP is mandatory, with forced enrolment after reset. One-time bootstrap/reset passwords must be replaced before staff access.

Uploads have size, type/magic-byte and geometry checks. They are recorded as `scan_status='not_scanned'`; the UI says **type-checked, not virus-scanned**. Antivirus scanning is not implemented. Money and deadlines use rules and integer arithmetic, not AI. The mock AI helper defaults on in demo configuration and can be disabled without affecting the catalogue/workflows; `/mock/**` is absent outside demo mode.

Playwright runs axe serious/critical checks on 15 pages, field-phone/offline journeys, keyboard controls and 200% text-size checks. This repository does not provide a CI workflow, and these automated checks do not establish complete accessibility conformance. Install, upgrades, bootstrap, backups and cross-directory restore are documented in [OPERATIONS](OPERATIONS.md) and [deploy/README](../deploy/README.md). Docker pins `WEB_DIST=/app/web`; the example environment does not override it.

## §9 — demonstration and remaining limitations

Fictional history is complete and automatically seeded on a fresh demo database. Alexey has a past inspected, paid hall booking with an undecided bond; Tom can demonstrate partial retention and a live DemoPay refund without waiting for a future event. [DEMO-GUIDE](DEMO-GUIDE.md) includes assisted intake, offline field work, independent approvals and generic result issuance.

DemoPay is an **in-app mock**, not an external provider's sandbox. Checkout, signed callbacks, ledger entries and refund completion are exercised, but the brief's external-provider test-mode requirement remains **partial** until an adapter is implemented. DemoMail also requires a real transport adapter for operational email/SMS. Integration endpoints can be configured; Council connectivity remains unverified. Outside demo mode mocks/online checkout are disabled, with counter and bank paths retained.

The code is MIT licensed. Only demo mode has resets/expiry; self-hosted installations have no timer or subscription. README offers implementation, migration, training and further development, without promising free ongoing support. Screenshots/home hero illustrations are static presentation material; case records and totals come from actions.
